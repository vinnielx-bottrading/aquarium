# Aquarium v21 — Hoàn thiện bối cảnh
24/11/2026. Tích hợp sáu ảnh mới cho núi, sân hiên đại dương, phòng kính Everest. Mỗi nơi có bản ngày/đêm cùng góc nhìn, ánh sáng toàn hồ và màu nước riêng. Giữ tập tính hai loài v20 và cây/rêu v19.

Chọn Bối cảnh rồi bấm Buổi tối/Ban ngày. Trong nhà dùng ảnh cũ với lớp chỉnh sáng; bốn cảnh ngoài phòng có cặp ảnh riêng. Nền là ảnh tĩnh; ánh sáng mang tính mỹ thuật 2.5D, không mô phỏng vật lý. Không tự triển khai website.

Chạy npm start; kiểm tra npm run build; xuất npm run export. GitHub/Vercel: Framework Other, Build npm run build, Output public. Không cần API key. Các hướng dẫn hành vi và chức năng cũ: docs/README_v20_history.md (ghi chú bối cảnh chưa làm ở tài liệu này đã được thay thế bởi v21).

Đã kiểm tra tự động mã nguồn và hồi quy. Chưa kiểm tra trực quan trong trình duyệt hoặc trên điện thoại thật trong đợt này.
